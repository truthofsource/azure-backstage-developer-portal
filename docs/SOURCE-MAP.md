# Source provenance and adaptations

**Terms used here:** Provenance means the record of where a release came from and how it was produced. A private endpoint gives a supported service an address on a private network; access permissions still apply.

This is derived from an implemented healthcare-services engineering portal. [Machine source map](source-map.json) records original file hashes and their public destinations without exposing a private roster, runtime environment, credentials, state or backups.

| Area | Retained implementation | Public adaptation |
| --- | --- | --- |
| Catalog | Real component/resource/group structure and dependencies | Example labels/links; private handbook entity omitted from seed |
| Release evidence | Actual pure evaluator and nine test-only tests | Consistent fictional repository, host and component labels |
| Startup / policy | Actual backend module selection and permission source | Labels only; supporting imports are excerpts, not a complete buildable app |
| Identity | Actual Microsoft provider and VM TechDocs overlays | Environment placeholders only; no real roster/client secret |
| Compose / VM operations | Four containers, networks, mounted secrets, readiness check and backup/restore source | Example target names; scripts remain operational examples, not automatically executed |
| Terraform | Actual VM/network/registry-reader/backup resources and variables | Remote backend/commissioned values omitted; public activation defaults Off; VM-only services group; bootstrap path relocated |
| Dockerfile | Actual dependency/runtime recipe and pinned base | Build context is explicitly incomplete in this public subset |
| Offline viewer / tests | New Python/HTML reference, catalog checks and Terraform mocks | Clearly labeled local reference, not a Backstage screenshot or live acceptance |

The source declared Backstage 1.55.0; that is a reviewed source version, not an assertion that it is the latest release. Maintained source and historical receipts can differ. This project makes no fresh cloud state, scan-cleanliness or deployed-image claim.

The Terraform variables retain some unused managed-alternative inputs to preserve their source context; no managed Container App, Flexible Server, private endpoint or dedicated vault is defined by this selected public root. Its copied network reservations remain visible. Do not use the public disabled defaults to reconcile the live adopted state.

Copied shell helpers are normalized to LF for Linux execution; .gitattributes and the manual validation workflow preserve/check that boundary.
