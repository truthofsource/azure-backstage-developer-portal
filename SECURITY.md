# Security scope

Use fictional data only. Do not commit actual credentials, engineer rosters, TLS private state, backups, provider tokens, subscription inputs or Terraform state. The source examples include no working deployment credentials.

This public subset is not an independently commissioned developer portal. The offline viewer has no authentication and is deliberately bound to loopback. Do not expose it as a protected service. The copied operational scripts require the owning host controls and privately reviewed inputs; do not run them against arbitrary systems.

Local unit/configuration tests and secret scanning do not establish that all Backstage dependencies, images or infrastructure are free of vulnerabilities. Evaluate the complete selected lockfile/image and current scanner databases before any real upgrade. Report public-repo issues without attaching secrets or source business records.
