Access path

Two identity layers

HTTPS → Caddy → OAuth2 Proxy → Backstage. Microsoft sign-in checks the engineering group; backend permissions control which actions are allowed.

Persistent state

Database + handbook

PostgreSQL stays on the internal Docker network. TechDocs publications mount read-only. Protected credentials and TLS state recover separately.

Cost and recovery

Start intentionally

Preflight → pull pinned images → start → verify → back up → stop → deallocate. The backup timer never starts a VM.
